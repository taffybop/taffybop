# P03-US07 — Preserve list and legal-clause hierarchy

Status: Done  
Story points: 5  
Estimate history: re-estimated 3→5 at readiness  
Phase: Phase 3 — Layout  
Priority: Medium  
Dependencies: P01-US02, P03-US04  
Feature flag: `parser.layout.outline_structure.enabled`
Started: 2026-08-01

## User story

As a structured-document consumer, I want bullets, nested lists, and legal
clauses represented with stable hierarchy, so that scope and parentage survive
serialization and table interruptions.

## Business value

Improves navigation, retrieval, and obligation extraction without relying on
document-specific marker cleanup.

## Problem statement

Datasheet nested feature bullets are flattened into one array, and settlement
clauses `a.`–`c.` remain plain paragraphs with no outline relationship across
an intervening table.

## In scope

- Native-PDF bullet, decimal, and lower-alpha marker, ordinal, nesting level,
  parent, and same-page continuation.
- List/outline continuity across one source-grounded table.
- Deterministic JSON and Markdown projection.

## Out of scope

- Legal interpretation or obligation classification.
- Reordering content based only on language plausibility.
- Form controls.
- Inline enumerations within one paragraph, cross-page edges, predecessor text
  repair, table reconstruction, and OCR/image/Office parity before M5.
- Upper-alpha, Roman, custom markers, and caption/callout continuations in v1.

## Technical approach

Extract a bounded native marker report only when enabled, then combine exact
marker bboxes, indentation bands, source ownership, and accepted reading order.
Project strict typed outline descriptors and `contains`, `outline_parent_of`,
`outline_next`, and `outline_continuation_of` relationships after US06 when
both flags are enabled. Preserve ambiguous candidates through exact predecessor
rollback and content-free concerns.

## Acceptance criteria

1. Component page 1 projects exactly two groups, 16 nodes, 11 `•` roots, five
   `◦` children, five parent edges, 11 sibling-next edges, 16 contains edges,
   and no continuation edge.
2. Settlement clauses `a.`, `b.`, and `c.` project exactly one ordered group,
   three ordinals, two sibling-next edges, three contains edges, and one
   table-to-`b.` continuation edge; the table remains a table and top-level
   public item.
3. All 19 markers, marker/item bboxes, source custody, predecessor values,
   levels, ordinals, parents, and relationship backlinks round-trip exactly
   with zero node loss, duplication, marker mutation, or visible duplication.
4. Inline Romans, plain parenthesized prose, broken sequences, ambiguous
   indentation, financial rows/tables, headers/footers, and form contributors
   produce zero false outline nodes.
5. Strict JSON, safe canonical Markdown/text, and semantic nested frontend DOM
   express the same hierarchy and continuation ownership with authoritative
   fallback on malformed sidecars.
6. Flag off performs zero US07 extraction/projection work and exactly restores
   the exact configured predecessor with all non-US07 flags unchanged;
   resources, paired p95 overhead, RSS,
   custody, idempotence, terminal re-entry, and zero-hosted-use gates pass.

## API and schema compatibility

Additive anchor-only `outline_group`, `outline_items`,
`outline_continuations`, and exact relationship descriptors plus typed IR
group/item descriptors. The canonical block schema stays unchanged. Existing
public items—including the component nested entries' legacy full-value
`marker` and `level`—values, table rows/cells, and physical reading order
remain byte-identical outside the anchor sidecar; malformed sidecars fall back
without inference. The
accepted contract is
[P03-outline-structure-policy.md](../decisions/P03-outline-structure-policy.md).

## Risks

- Marker-like prose misclassified as a list.
- Table interruption splitting one outline.

## Rollback

Set `PARSER_LAYOUT_OUTLINE_STRUCTURE_ENABLED=false`. This performs zero US07
source extraction or projection and restores the exact configured predecessor
with every non-US07 flag unchanged. Page-local failures restore the affected
page; source/document or final-validation failures restore the whole US07
stage.
