# P01-US01 — Introduce versioned evidence and relationship IR

Status: Done  
Story points: 5  
Phase: Phase 1 — Shared IR  
Priority: High  
Dependencies: P00-US10  
Feature flag: `parser.shared_ir.enabled`

## User story

As a parser integrator, I want elements, evidence, and relationships represented
explicitly, so that every format and analyzer can contribute without flattening
source truth.

## Business value

Enables safe reconciliation, provenance, extensibility, and auditability while
preventing format-specific cleanup and serializer forks.

## Problem statement

The current item model mixes caption, OCR, source, confidence, and presentation
fields. It cannot represent alternatives or `caption_of`/`source_note_of` links.

## In scope

- Internal versioned `Document/Page/Region/Element/Evidence/Relationship` records.
- Stable IDs, coordinate units/transforms, evidence methods, and relationship types.
- Additive adapter from current normalized items.

## Out of scope

- Changing extraction decisions.
- New public fields by default.
- Chart-specific values or model inference.

## Technical approach

Introduce an internal IR behind a default-off flag, populate it from existing
normalized data, and preserve a compatibility projection to the current response.

## Acceptance criteria

1. IR round-trips all current item types without text/order/bbox loss.
2. Evidence records distinguish native, OCR, vector, embedded, recovered, and model methods.
3. Relationships support at least contains, caption_of, source_note_of, legend_of, axis_of, and reading_before.
4. Stable IDs are deterministic for identical input/evidence.
5. With the flag off, current API output hashes remain unchanged.

## Dedicated tests

- Unit tests: [tests/stories/phase_01/test_p01_us01_ir_contract.py](../../../tests/stories/phase_01/test_p01_us01_ir_contract.py)
- Integration tests: current PDF and image items round-trip through IR.
- Negative tests: dangling IDs, invalid transforms, cycles in forbidden relationships.
- Contract tests: v1 compatibility projection.
- Fixture-based tests: Phase 00 synthetic/catastrophe manifests.

## Regression impact

Run Phase 00–01, API/schema, serializer, image, table, and input tests.

## Metrics

- Before: ad hoc item fields and no general relationship graph.
- Target: 100% current items round-trip; 0 dangling relationships; flag-off hash parity.
- After: `../metrics.md`.

## API and schema compatibility

Internal only in this story. Public v1 output remains unchanged.

## Risks

- Over-general schema that slows delivery.
- Non-deterministic IDs or coordinate confusion.

## Rollback

Disable `parser.shared_ir.enabled`; retain the legacy item path.

- Related gaps: `GAP-PROVENANCE-001`, `GAP-BBOX-001`,
  `GAP-LAYOUT-001`, `GAP-LINK-001`.
- Cases/pages/regions: health-report p1 Figures 3.9/3.10 (`x=45–542,
  y=58–615`) and two StatLinks (`y≈310`, `y≈605`); finance-10k pp1–3
  statement tables; purchase-agreement p1 redline/date runs; uber-earnings p1
  photograph/title/date and p3 diagrams.
- Current behavior: all 291 top-level items have bboxes and source labels, but
  confidence covers only 23.02%; table cells, chart marks, formatting runs,
  link annotations, and diagram relations lack typed field-level grounding.
  Some item text lies outside its bbox, and generated/derived evidence can look
  native or caption-authored.
- Generalized behavior: each semantic claim round-trips through stable element,
  evidence, relationship, and bbox IDs with declared source method, box role,
  units/transform, confidence scope, and link/derivation provenance.
- Acceptance tests: positive—finance tables and settlement prose round-trip
  unchanged; target—retain health annotations and purchase run evidence;
  non-target—esg-metrics p1 unannotated navigation remains visible text with a
  null link target; negative—reject dangling IDs, invalid transforms, forbidden
  cycles, derived images labeled native, and text localized only by a
  non-containing bbox.
- Metrics/performance: preserve 100% top-level bbox/source coverage, achieve
  100% IR round-trip and 0 dangling relationships, and retain flag-off hash
  parity. Record IR p50/p95/RSS deltas against P00-US10; total Phase 01 p95
  overhead remains at or below 5%.
