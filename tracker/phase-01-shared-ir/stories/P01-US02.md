# P01-US02 — Normalize elements without flattening evidence

Status: Done  
Story points: 5  
Phase: Phase 1 — Shared IR  
Priority: High  
Dependencies: P01-US01  
Feature flag: `parser.shared_ir.normalization.enabled`

## User story

As a downstream consumer, I want normalized elements to retain their evidence and
relationships, so that captions, children, alternatives, and provenance are not
silently lost.

## Business value

Removes the architectural cause of the missing Exhibit 7 caption and merged
Exhibit 8 item before document-specific fixes are added.

## Problem statement

Current normalization returns after a table, ignores its caption links, and
combines visual captions with all children into one string.

## In scope

- IR normalization traversal with explicit seen/ownership semantics.
- Preserve raw caption, child, footnote, alternative, and annotation references.
- Source breakdown and multidimensional confidence placeholders.

## Out of scope

- Final caption classification rules.
- Text/font repair.
- Public serializer changes.

## Technical approach

Normalize graph nodes once while retaining typed edges and per-evidence bboxes.
Projection may preserve legacy flattened fields until later stories.

## Acceptance criteria

1. No referenced caption/child/footnote is dropped solely because its owner is emitted.
2. Caption and child evidence remain distinct records with original bboxes.
3. Mixed native/OCR items expose a source breakdown rather than one false global source.
4. Unresolved references produce concerns, not silent loss.
5. Legacy projection remains contract-compatible with the flag off.

## Dedicated tests

- Unit tests: [tests/stories/phase_01/test_p01_us02_normalization.py](../../../tests/stories/phase_01/test_p01_us02_normalization.py)
- Integration tests: raw Docling table/picture graphs from Phase 00.
- Negative tests: duplicate refs, dangling refs, shared child, cyclic group.
- Contract tests: legacy item projection and additive IR validation.
- Fixture-based tests: catastrophe raw graph and synthetic caption/child graph.

## Regression impact

Run Phase 00–01 plus existing pipeline, image, table, and serializer tests.

## Metrics

- Before: Exhibit 7 caption dropped; Exhibit 8 caption/children flattened.
- Target: 100% referenced nodes retained; 0 silent dangling-reference losses.
- After: `../metrics.md`.

## API and schema compatibility

No default public change; additive debug/IR exposure requires separate approval.

## Risks

- Duplicate traversal or altered reading order.
- Larger internal objects.

## Rollback

Disable the normalization flag and use legacy normalization.
