## Functional-fidelity amendment — 2026-08-13

Dense-grid reconciliation now admits one narrowly bounded low-margin
exception: an exact vector candidate may win only when it is explicitly marked
as logical-row recovery, its geometry covers every rectangular slot, its token
set covers the alternative, and it loses neither rows nor columns. Ordinary
low-margin conflicts remain unresolved. This prevents a Docling `51x12`
matrix from defeating the source-correct timetable `52x13` matrix without
weakening the fail-closed rule for clinical, financial, form, or chart
alternatives.

Acceptance evidence is
`tests/stories/phase_04/test_p04_us02_table_reconciliation.py`:
`test_exact_source_grid_recovery_resolves_collapsed_low_margin_candidate` and
`test_low_margin_exception_requires_explicit_logical_row_recovery`. The
end-to-end hashes and fresh Llama job binding are recorded in
`../../benchmarks/llamaparse-15/runs/functional-fidelity-20260813/table-source-truth-audit.md`.

## User story

As a table consumer, I want competing table candidates reconciled by source
coverage and geometry, so that the most faithful structure is selected without loss.

## Business value

Uses current Docling and pdfplumber strengths while preventing opaque engine
precedence, duplicate tables, and cell omissions.

## Problem statement

Both engines can identify overlapping tables, but current merge logic lacks a
general evidence score and transparent cell-level alternatives.

## In scope

- Candidate overlap/alignment, text coverage, grid, and provenance scoring.
- Selected table plus retained alternatives/concerns.
- Caption and source-note relationship preservation.

## Out of scope

- New table detector/model.
- Multi-page continuation.

## Technical approach

Align candidates by page geometry, compare grid/cell evidence, select only above
a margin, and retain unresolved alternatives rather than silently merging.

## Acceptance criteria

1. Exhibit 7 selects the 30-cell source-faithful candidate.
2. Duplicate overlapping tables emit one canonical table.
3. Conflicting grids below the selection margin remain unresolved with concerns.
4. No selected cell loses text/bbox/provenance available in the winning evidence.
5. Caption/source-note links survive selection.
