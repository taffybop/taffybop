## User story

As a visual-content consumer, I want chart, diagram, and model confidence
calibrated against grounded truth, so that plausible but unsupported structure
is withheld.

## Business value

Visual calibration limits hallucination and false precision while preserving
useful structured output when source support is strong.

## Problem statement

OCR, classifier, structure, value, relationship, and model scores are not
interchangeable. Premium-looking visual output can still contain impossible or
ungrounded claims.

## In scope

- Versioned fit/evaluation partitions for charts, diagrams, and model-generated
  hypotheses.
- Separate detection, structure, completeness, value, and generated-claim
  calibration.
- Tolerance-aware chart correctness and evidence-aware diagram/model outcomes.
- Per-type accept, fallback, and abstention thresholds.

## Out of scope

- Reconstructing new chart or diagram structure.
- Correcting rejected claims using semantic plausibility.
- Review packet construction or hosted-provider selection.

## Technical approach

Calibrate only validated P05/P06 hypotheses against disjoint grounded holdouts.
Use explicit/derived status, tolerance, provenance coverage, and validator
outcomes as features permitted by the approved calibration contract.

## Acceptance criteria

1. Chart, diagram, and model datasets have versioned, disjoint, leakage-checked
   fit/evaluation partitions, including supported and intentionally unknowable
   controls.
2. Every enabled confidence dimension meets approved held-out ECE, Brier,
   coverage, and unsupported-artifact targets by visual category.
3. A chart value without mark/axis provenance, an ambiguous diagram edge, or an
   ungrounded generated claim is never promoted by calibration.
4. The impossible annual-below-1H control and fabricated relation controls are
   withheld with the expected concern.
5. Categories that miss targets remain disabled and use P05/P06 grounded
   fallback.
6. Disabling the flag restores P06 raw confidence, validators, and routing.
7. The no-caption photograph, New Zealand/Australia identity, exact unprinted
   value without mark/axis/tolerance, and directed edge without arrowhead are
   withheld regardless of classifier/OCR/model score; printed endpoints and
   node labels remain positive controls.

## API and schema compatibility

## Risks

- Visual ground truth and tolerance choices can bias calibration.
- Model upgrades invalidate previous calibration.
- Rare chart and diagram types may lack sufficient evidence.

## Rollback

validators and grounded fallback.
