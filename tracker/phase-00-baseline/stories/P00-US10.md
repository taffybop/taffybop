## User story

As a delivery owner, I want one reproducible multi-case runner and semantic
report contract, so that every milestone compares parser versions, reviewed
truth, and expert output without overwriting prior evidence.

## Business value

Makes quality, latency, memory, model cost, and regression claims comparable
across stories and release candidates.

## Problem statement

The analysis run proves that all 15 cases can execute, but the tooling is not
yet an approved test capability. Raw token similarity also hides severe grid,
order, OCR, and provenance defects.

## In scope

- Isolated fixed-configuration execution with immutable run directories.
- Source/output hashes, versions, flags, engines, environment, timing, RSS,
  warnings, and errors.
- Semantic text, layout/order, table, chart, diagram, Markdown, JSON,
  hallucination, performance, and cost reports.
- Source-reviewed inclusion/exclusion masks for expert parity.

## Out of scope

- Parser changes or automatic acceptance of a candidate.
- One undifferentiated quality score.
- Live hosted-model calls in the default baseline.

## Technical approach

Promote the analysis runner into bounded benchmark tooling. Compare stable
element IDs and reviewed annotations; retain token/string metrics only as
diagnostic drift signals. Write every run to a new ID and fail closed on missing
identity or environment fields.

## Acceptance criteria

1. A fixed command runs every selected case in isolation and never overwrites a
   prior run or expert artifact.
2. Runs record application/source hash, full configuration, feature flags,
   engines/models, environment, timestamps, latency, CPU, RSS, output hashes,
   warnings, and errors.
3. Reports separate text, layout, reading order, tables, charts, diagrams,
   Markdown, JSON, hallucination, performance, and cost.
4. Expert parity includes only the reviewed source-supported portion and
   preserves justified safer disagreements.
5. Missing cases, changed source hashes, partial output, and silent skips fail
   with actionable diagnostics.
6. Repeated runs on the reference environment reproduce quality counts and
   stable outputs within declared performance tolerance.

sources, annotations, and the prior analysis run.
