## User story

As a quality reviewer, I want source-reviewed truth for the catastrophe page, so
that our parser and external benchmarks are evaluated against the PDF rather than
against each other.

## Business value

Creates an auditable regression fixture for damaged fonts, captions, a table,
vector charts, source notes, reading order, and unsupported derived values.

## Problem statement

The hash-pinned expert output repairs useful content and represents the current
Exhibit 7 table without a false span, but it emits unprinted chart values without
per-value method/tolerance and includes material year/value associations outside
the selected vector tolerance. Older assessment prose used a different expert
JSON that contained a duplicate title, a false table span, and an impossible
annual-below-1H value. Those three shapes remain synthetic negative controls,
not defects attributed to the currently registered expert artifact. Neither
parser output is itself ground truth.

## In scope

- Artifact hashes/manifest and source-use decision.
- Text spans, element types, bboxes, relationships, table cells, and reading order.
- Chart labels and vector-measurement truth with method/tolerance.
- Explicit unknown/unsupported annotations.

## Out of scope

- Parser changes.
- Treating inferred integers as literal PDF data.
- Committing the source PDF unless usage rights are approved.

## Technical approach

Encode reviewed annotations using P00-US01 contracts. If source redistribution is
not approved, use a private fixture reference plus redistributable synthetic
derivatives for CI.

## Acceptance criteria

1. Manifest hashes match all supplied artifacts.
2. The exact damaged sentence, both exhibit titles, source note, logo text, footer, and printed page label are annotated.
3. Exhibit 7 contains 30 explicit cells and no fabricated row span.
4. Chart truth distinguishes printed labels from 88 approximate vector measurements and records tolerance/calibration.
5. At least two negative annotations cover duplicate titles and unsupported values.
6. A documented source-rights decision determines public, private, or synthetic storage.

## Dedicated tests

- Unit tests: annotation and bbox/tolerance validators.
- Integration tests: [tests/stories/phase_00/test_p00_us02_catastrophe_truth.py](../../../tests/stories/phase_00/test_p00_us02_catastrophe_truth.py)
- Negative tests: false row span, annual below 1H, duplicate title, unsupported exact value.
- Contract tests: P00-US01 manifest/annotation schemas.
- Fixture-based tests: supplied artifacts or approved private/synthetic equivalents.

## Regression impact

Run Phase 00 contract tests and existing parser tests; parser outputs remain
baseline evidence and are not expected to change.
