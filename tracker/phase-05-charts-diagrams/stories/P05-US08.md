## User story

As a raster-chart consumer, I want points on supported line charts measured
against grounded axes, so that approximate trends and values retain pixel
provenance and uncertainty.

## Business value

Adds a common raster chart type without conflating line pixels with literal
source values or expanding the bar analyzer into an unbounded CV story.

## Problem statement

P05-US06 structures raster axes, categories, and legends but does not identify
line marks or data points. Lines require separate tracing, series association,
sampling, and uncertainty behavior.

## In scope

- Simple 2-D line charts with linear x/y axes and clearly separated series.
- Visible point markers or unambiguous line/category intersections.
- Pixel path/point evidence, category/series association, and
  `raster_measured` values with tolerance.
- Explicit gaps and unresolved output for ambiguous intersections.

## Out of scope

- Curved/smoothed, area, stacked-area, scatter-only, log, dual-axis, 3-D, or
  densely overlapping line charts.
- Inferring hidden points between categories.
- Semantic trend descriptions or model reasoning.

## Technical approach

Trace supported line pixels within the P05-US06 plot region, associate paths
with legend series, sample only evidenced category positions, calibrate through
the grounded axes, and pass values and tolerances through P05-US05 validation.

## Acceptance criteria

1. Approved simple 2-D linear fixtures recover all supported series paths and
   evidenced category points with source pixel geometry.
2. Every emitted value references its point/path, calibrated axes, category,
   series, method, confidence, and numeric tolerance.
3. Explicit printed labels remain `explicit_text`; geometry-derived points are
   `raster_measured`.
4. Values meet each fixture's approved pixel-derived tolerance.
5. Gaps, crossings, occlusion, or unsupported axes emit no affected values and
   retain fallback structure plus concerns.
6. No bar, area, smoothed, or inferred intermediate point is emitted.

## API and schema compatibility

Adds default-off raster line paths/points through the existing chart schema;
legacy and P05-US05 fallback output remain available.

## Risks

- Anti-aliasing, compression, grid lines, and series crossings can break path
  tracing.
- Line thickness and sparse pixels bound numerical precision.
- Legend colors may be indistinguishable after grayscale conversion.

## Rollback

Disable raster line values; retain P05-US06 structure and P05-US05 fallback.

  **Unmeasured/Blocked**; retired local timings cannot substitute, and latency
  cannot compensate for a quality or reliability failure.
- Flag/rollback: `parser.charts.raster_line_values.enabled`; disabling it
  removes line values and retains P05-US06 structure/P05-US05 fallback.
