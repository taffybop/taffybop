## User story

As a chart analyzer, I want source vector primitives normalized with transforms
and panel ownership, so that later measurement uses PDF evidence instead of pixels.

## Business value

Provides a CPU-cheap, offline path for the catastrophe chart and many native PDFs.

## Problem statement

The source has 91 chart curves and recoverable colors, but current vector logic
only uses thin rules for tables.

## In scope

- Curves/rectangles/lines/text anchors, fills/strokes, clipping, transforms.
- Chart-region filtering, panel candidates, stable mark IDs.
- Primitive provenance and unsupported-shape concerns.

## Out of scope

- Axis calibration, series semantics, or numeric values.
- Raster charts.

## Technical approach

Normalize page/Form-XObject primitives into chart-local and page coordinates,
cluster mark candidates, and retain original object/path references.

## Acceptance criteria

1. Catastrophe chart inventory accounts for the expected chart curves/mark candidates within reviewed tolerance.
2. Dark/light fills and all transforms are preserved.
3. Four panel candidates and stable mark IDs are available for later stories.
4. Table/logo/decorative primitives outside the chart are excluded.
5. Clipped/unsupported geometry produces concerns rather than silent approximation.
