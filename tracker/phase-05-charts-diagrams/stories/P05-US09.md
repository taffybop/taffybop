## Release-first acceptance criteria

- Implemented state: the default-off raster-analysis umbrella is now the sole
  public admission and rollback boundary for raster structure and values. It
  enforces bounded crop dimensions, total pixels, work, timeout, quality, and
  coordinate-normalization declarations before committing raster authority.
- Release behavior: supported direct-image/PDF-render inputs share the same
  normalized semantic contract, while resource-limit, timeout, low-quality,
  blurred, occluded, unsupported, under-grounded, incomplete, or malformed
  results atomically restore the P05-US05 fallback without partial values.
- Sequence: after P05-US07, P05-US08, and P05-US05.
- Basic validation: one supported direct/PDF-render representative flow reaches
  equivalent semantic output within declared coordinate tolerance, one

  falls back without partial values, and flag-off is unchanged.
- Deferred: detailed CPU/RSS/latency thresholds, exhaustive semantic-twin
  campaigns, stress/soak, hardware-specific proof, and evidence manifests.

Basic input/time bounds and safe fallback remain required production behavior.

## User story

As an operator, I want raster chart analysis bounded by parity, quality, and
resource gates, so that unsupported inputs fall back predictably regardless of
their input path.

## Business value

Makes raster support safe to enable by preventing low-quality claims, runaway
pixel processing, and divergent results between direct images and PDF renders.

## Problem statement

Raster structure and mark analyzers need a single release boundary. Without it,
low-resolution or oversized crops can emit partial structure, consume
unbounded resources, or behave differently when the same pixels arrive through
different adapters.

## In scope

- Direct-image/PDF-render semantic parity checks and coordinate tolerances.
- Resolution, blur/occlusion, crop-size, pixel, CPU, memory, and timeout gates.
- All-or-safe-partial quality policy and P05-US05 fallback selection.
- Gate decisions, metrics, and stable reason concerns.

## Out of scope

- New OCR, axis, legend, bar, line, or other mark extraction.
- Changing vector-chart behavior.
- Model/VLM escalation.

## Technical approach

Wrap the P05-US06–US08 raster analyzers in a deterministic pre/post gate. Reject
over-budget work before analysis, validate supported structure and value
coverage afterward, compare semantic twins within declared coordinate
tolerance, and return the canonical P05-US05 fallback on failure.

## Acceptance criteria

1. Approved direct-image/PDF-render twins produce equivalent text, chart roles,
   relationships, methods, values, tolerances, and concerns after coordinate
   normalization.
2. Pixel, crop, CPU, memory, and timeout limits are enforced at their configured
   boundaries.
3. Low-resolution, blurred, occluded, ambiguous, or under-grounded fixtures
   return the approved fallback and stable quality concerns.
4. A gate failure emits no partial bar/line values and preserves title, labels,
   bbox, provenance, confidence dimensions, and concerns.
5. This story introduces no new extraction algorithm or chart type.
6. Flag-off output exactly matches P05-US05 behavior.

## API and schema compatibility

The umbrella gate is default-off. It exposes only existing additive chart
structure/values and stable concerns; flag-off public output remains unchanged.

## Risks

- Quality thresholds may reject useful but imperfect charts.
- Hardware-dependent CPU/memory measurements need a pinned reference profile.
- Loose parity tolerances can hide adapter transform errors.

## Rollback

Disable raster analysis to stop raster structure/value emission and return the
canonical P05-US05 fallback.

## Benchmark evidence — LlamaParse-15

- Gaps: `GAP-DIAGNOSTICS-001`, `GAP-PROVENANCE-001`,
  `GAP-BBOX-001`, and `GAP-SERIALIZATION-001`.
- Source/current behavior: the corpus provides PDF-path raster evidence
  (`manufacturing-report` p3 and Uber raster assets) but no approved
  source-equivalent direct-image/PDF-render twin. `uber-earnings` retains the
  local M0 2,589.5 MiB memory guard; retired local latency values are not live
  ceilings.
- Generalized behavior: one deterministic pre/post gate normalizes coordinates,
  enforces pixel/quality/CPU/memory/timeout budgets, validates semantic parity,
  and returns one canonical fallback with stable reasons and no partial values.
- Test slice: reviewed direct-image/PDF semantic twins and supported analyzers as
  positives; vector charts as non-targets; blur, low resolution, occlusion,
  oversize, timeout, memory/CPU boundary, parity mismatch, and partial-output
  negatives.
- Acceptance/metrics/performance: 100% approved twin parity and boundary
  enforcement, 0 unsafe partial values, deterministic fallback, and measured
  peak RSS, pixels, rejected-work overhead, and output size within approved
  budgets. The sole latency benchmark is
  [`LlamaParse latency reference v1`](../../benchmarks/llamaparse-15/latency-reference-v1.md).
  Initial one-shot values are planning only. Before Definition of Done, collect
  at least five interleaved candidate/Llama observations for every applicable
  case and require candidate p50 and inclusive nearest-rank p95 to be no
  greater than paired Llama p50/p95 per case, without average masking or
  dropped failures. Semantically incomparable input/output is
  **Unmeasured/Blocked**; retired local timings cannot substitute, and latency
  cannot compensate for a quality or reliability failure.
- Flag/rollback: `parser.charts.raster_analysis.enabled`; disabling the umbrella
  gate stops raster structure/value emission and returns P05-US05 fallback.
