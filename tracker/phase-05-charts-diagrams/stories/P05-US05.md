## Release-first acceptance criteria

- Implemented state: the default-off structured-output flag now validates
  evidence coverage, axis ranges, confidence, tolerance, method grounding,
  basic stack constraints, and supported series relations before admitting
  chart points to authoritative output.
- Release behavior: valid points serialize deterministically through the
  chart-owned additive JSON sidecar and canonical Markdown with one caption;
  invalid or ungrounded points are withheld without correction, while complete
  validation or serialization failure atomically retains the useful
  unstructured chart fallback and emits targeted concerns.
- Sequence: after P05-US04 and canonical serialization; required by later
  raster/Office/model chart paths.
- Basic validation: one valid structured chart serializes once, one invalid or
  ungrounded value is withheld with a concern, one duplicate caption is
  suppressed, and flag-off returns existing fallback output.
- Deferred: exhaustive domain constraints, calibration/performance campaigns,
  hallucination/adversarial matrices, evidence manifests, and independent
  review.

This release section supersedes stricter validation requirements below.

## User story

As an agent consuming chart data, I want invalid or ungrounded values withheld and
valid structure serialized once, so that automated decisions remain auditable.

## Business value

Prevents failures like annual total below 1H, duplicate Exhibit 8 titles, and
high-confidence tables without cell provenance.

## Problem statement

The benchmark emits an impossible Americas 2023 pair and duplicates its chart
title; our system has no structured validator or safe chart serialization.

## In scope

- Structural/numeric validators and concern severity.
- Confidence dimensions and safe point/series withholding.
- Canonical JSON and Markdown/table projection with one caption.

## Out of scope

- Correcting invalid values by semantic guess.
- Raster or model extraction.

## Technical approach

Validate evidence coverage, axis range, stack constraints, annual≥1H, and
caption uniqueness. Serialize only structures above approved thresholds.

## Acceptance criteria

1. No annual total below 1H is emitted as valid.
2. Every serialized cell/point has mark, axis, method, confidence, and tolerance.
3. Exhibit 8 title appears exactly once.
4. Failed validation returns chart fallback plus concerns, not a fabricated table.
5. Item-level confidence does not present OCR confidence as structural/value confidence.

## Benchmark evidence — LlamaParse-15

- Gaps: `GAP-CHART-002`, `GAP-PROVENANCE-001`,
  `GAP-DIAGNOSTICS-001`, and `GAP-SERIALIZATION-001`.
- Source/current behavior: expert controls contain invalid or unsupported data:
  catastrophe Exhibit 8 has year/series misassociation, health p1 Figure 3.10
  has bubble rows materially off visible marks, and manufacturing p2 Figure 2.8
  shifts printed stacked-bar values across series. M0 avoids those values but
  duplicates/fuses chart text and has no structured validator/serializer.
- Generalized behavior: validate evidence coverage, axis/stack constraints,
  explicit-versus-derived method, tolerance, caption uniqueness, and semantic
  projection parity; invalid fields are withheld with targeted concerns.
- Test slice: one validated positive chart from each supported method;
  finance/table and unstructured fallback non-targets; impossible stack,
  out-of-axis value, missing provenance/tolerance, duplicate caption, and
  wrong-series negatives.
- Acceptance/metrics/performance: 0 invalid/ungrounded values, 100% emitted-value
  provenance/tolerance, 0 duplicate titles, and JSON/Markdown semantic parity.
  Record validation/fallback rate, peak RSS, and output-size deltas against
  local M0 manufacturing 1,825.8 MiB and health 1,437.0 MiB. The sole latency
  benchmark is
  [`LlamaParse latency reference v1`](../../benchmarks/llamaparse-15/latency-reference-v1.md).
  Initial one-shot values are planning only. Before Definition of Done, collect
  at least five interleaved candidate/Llama observations for every applicable
  case and require candidate p50 and inclusive nearest-rank p95 to be no
  greater than paired Llama p50/p95 per case, without average masking or
  dropped failures. Semantically incomparable input/output is
  **Unmeasured/Blocked**; retired local timings cannot substitute, and latency
  cannot compensate for a quality or reliability failure.
- Flag/rollback: `parser.charts.structured_output.enabled`; disabling it removes
  structured projections and preserves evidence-backed fallback/diagnostics.
