## User story

As a data consumer, I want vector chart values measured with source geometry and
uncertainty, so that derived data is useful without pretending to be literal text.

## Business value

Provides low-cost structured chart data for native PDFs and avoids opaque,
overconfident model-generated integers.

## Problem statement

The catastrophe values are not printed or embedded; they are measurable only
from quantized stacked bars and calibrated axes.

## In scope

- Common vertical linear bars, grouped/stacked segments, baseline and height measurement.
- `vector_measured` method, mark/axis IDs, raw value, display value, tolerance.
- Low-height/rounding uncertainty.

## Out of scope

- Raster measurement.
- Log/dual/3D charts.
- Guessing exact hidden source data.

## Technical approach

Measure chart-local geometry, transform through the approved axis calibration,
and propagate coordinate/residual/quantization uncertainty.

## Acceptance criteria

1. Catastrophe produces 88 candidate data points linked to mark and axis evidence.
2. Values match reviewed two-decimal vector estimates within approved tolerance.
3. Every point is labeled `vector_measured`, never `explicit_text`.
4. Small/ambiguous bars receive larger uncertainty or remain unresolved.
5. No value is emitted when required mark/axis/series evidence is missing.
