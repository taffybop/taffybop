# P02 Font Fixture, Dependency, and Embedded-Program Policy

Status: Accepted  
Date: 2026-07-29  
Applies to: P02-US01 through P02-US04

## Decision

Phase 2 uses the current local PDF stack for font integrity:

- `pdfminer.six==20260107` for PDF object identities, resource/font
  dictionaries, Type0 descendants, `/Encoding`, `/ToUnicode`,
  `/CIDToGIDMap`, content-stream character codes, widths/advances, glyph-run
  geometry, and embedded-program state;
- `pypdfium2==5.12.1` as the existing native-text and rendered-character
  cross-check;
- `pdfplumber==0.11.10` only where its existing higher-level geometry is useful.

Because production code will import `pdfminer.six` directly, its already
installed version becomes an explicit direct project pin rather than relying
on `pdfplumber`'s transitive dependency. This adds no new installed
distribution or model.

Local package metadata declares `pdfminer.six` MIT and `pypdfium2` under
BSD-3-Clause/Apache-2.0 plus its documented dependency licenses. No model,
network service, or external font package is introduced by this decision.

## Fixture policy

The public/redistributable project corpus is authoritative for real-document
targets and controls:

- `catastrophe-recap.pdf` supplies both confirmed malformed Type0 subsets;
- `finance-10k.pdf` supplies healthy native/Type0 controls;
- other approved corpus PDFs may be used as healthy WinAnsi, multilingual, or
  unusual-font non-target controls after their expected classification is
  pinned.

Missing-map, non-identity, no-embedded-program, intentional-spacing, private-use,
replacement-character, and malformed-input edges use deterministic test-only
PDF builders or bounded synthetic font/run records. Synthetic PDFs use PDF
standard fonts, empty/minimal streams, or generated dictionary/content objects;
they do not copy, embed, or redistribute third-party font programs.

Fixtures are immutable by hash or are regenerated byte-identically by a
versioned builder. Tests must distinguish:

1. a present mapping that is suspicious;
2. a missing mapping;
3. an identity versus non-identity CID-to-GID mapping;
4. embedded-program present versus absent;
5. ordinary printed spaces versus positive-advance glyphs incorrectly mapped
   to spaces.

This provides all required positive, healthy, and negative fixture classes
without downloading a font or changing corpus custody.

## Security and retention

- Parse font dictionaries and streams in memory under the existing upload,
  page, and document timeout bounds.
- Bound decoded stream size, used-code count, nesting, and diagnostic output.
- Do not execute font programs.
- Do not persist, return, log, commit, or redistribute extracted `FontFile`,
  `FontFile2`, or `FontFile3` bytes.
- Record only object identity, declared properties, counts, hashes where
  necessary, reason codes, run bboxes, and confidence basis.
- Malformed or unsupported font structures produce explicit unresolved/audit
  concerns; they never fail the whole parse merely because repair is
  unavailable.
- P02-US01 detects and reports only. It must not rewrite native text.

## Rollback

`PARSER_TEXT_INTEGRITY_FONT_AUDIT_ENABLED=false` bypasses the audit and retains
the exact prior native extraction and public response. Removing the explicit
direct `pdfminer.six` pin is safe only if no production module imports it
directly.
