# P02-US02 — Recover safe identity-mapped font text

Status: Done  
Story points: 5  
Phase: Phase 2 — Text Integrity  
Priority: High  
Dependencies: P02-US01  
Feature flag: `parser.text_integrity.font_recovery.enabled`

## User story

As a reader, I want damaged native spans recovered from embedded font evidence
when deterministic, so that visible text remains accurate without OCR.

## Business value

Repairs the exact catastrophe sentence with low CPU/memory cost and stronger
provenance than language-model completion.

## Problem statement

Identity-H and identity CID-to-GID mappings retain correct glyph identities in
the embedded TrueType cmap, but the parser currently ignores that evidence.

## In scope

- Safe recovery for audited identity-mapped embedded TrueType fonts.
- Original/recovered alternatives, glyph boxes, method, and confidence.
- Refusal/concerns for unsupported mappings.

## Out of scope

- General arbitrary-font deobfuscation.
- OCR fallback.
- Language-model repair.

## Technical approach

Invert the embedded cmap only when identity and one-to-one evidence checks pass;
validate advances and used glyphs; never overwrite the original evidence.

## Acceptance criteria

1. The exact `Windstorm Éowyn … (€620 million)` sentence is recovered.
2. Chart labels encoded by the second malformed font recover where evidence is safe.
3. Healthy text remains byte-equivalent.
4. Non-identity, ambiguous, missing-program, and many-to-one cases remain unresolved with concerns.
5. Every recovered code point links to original glyph/font/bbox evidence.

- Unit tests: [tests/stories/phase_02/test_p02_us02_font_recovery.py](../../../tests/stories/phase_02/test_p02_us02_font_recovery.py)

## Regression impact

Run Phase 00–02, Unicode/multilingual, native PDF, serializer, and contract suites.

## Metrics

- Before: target sentence fails exact match.
- Target: exact match passes; 0 healthy-font rewrites; 100% recovered-token grounding.
- After: `../metrics.md`.

## API and schema compatibility

Text changes only when the flag is enabled and evidence is deterministic; fields
are additive or projected compatibly.

## Risks

- Incorrect cmap inversion on unusual fonts.
- Embedded-font redistribution if implementation persists artifacts.

## Rollback

Disable recovery; retain audit concerns and original native text.
