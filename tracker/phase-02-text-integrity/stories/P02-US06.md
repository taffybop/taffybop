# P02-US06 — Preserve spatial repetition and short tokens

Status: Done  
Story points: 3  
Phase: Phase 2 — Text Integrity  
Priority: High  
Dependencies: P02-US04, P02-US05  
Feature flag: `parser.ocr.spatial_token_preservation.enabled`

## User story

As a layout-aware consumer, I want repeated text at different coordinates and
short supported alternatives retained, so that chart labels and legends keep meaning.

## Business value

Preserves all twelve year positions and prevents a global threshold from silently
removing short, structurally important tokens such as `1H`.

## Problem statement

Text-only `dict.fromkeys()` collapses spatial repetition; `iH` at 0.4437 is
discarded with no legend-role corroboration.

## In scope

- Overlap-aware rather than text-only deduplication.
- Word/line boxes and positional repetitions.
- Retention of short low-confidence alternatives with corroborating geometry/role.

## Out of scope

- Forcing `iH` to `1H` without evidence.
- Chart legend association, handled in Phase 05.

## Technical approach

Deduplicate only overlapping equivalent candidates; retain non-overlapping
occurrences and short alternatives as evidence with concern/confidence.

## Acceptance criteria

1. All 12 distinct year-label bboxes remain addressable.
2. Overlapping PSM alternatives collapse to one selected candidate plus diagnostics.
3. Short `iH`/`1H` hypotheses remain available with bbox and confidence.
4. Repeated headers/footers at distinct locations are not merged within a page.
5. Canonical prose does not gain unsupported short OCR noise.

## Dedicated tests

- Unit tests: overlap-aware dedup and short-token policy.
- Integration tests: [tests/stories/phase_02/test_p02_us06_spatial_tokens.py](../../../tests/stories/phase_02/test_p02_us06_spatial_tokens.py)
- Negative tests: identical overlapping OCR, distant repeated text, isolated noise.
- Contract tests: token occurrence IDs/bboxes and canonical projection.
- Fixture-based tests: catastrophe chart and repeated-label controls.

## Regression impact

Run Phase 00–02, image/OCR, layout, serializer, and output-size tests.

## Metrics

- Before: 12 positions collapse to one triplet in primary text; `iH` unavailable.
- Target: 12/12 positions; 0 duplicate overlaps; short alternative grounded.
- After: `../metrics.md`.

## API and schema compatibility

Additive token occurrences; canonical prose behavior changes only behind flag.

## Risks

- Increased JSON size.
- Retaining too much low-confidence noise.

## Rollback

Disable spatial preservation and use legacy line deduplication.
