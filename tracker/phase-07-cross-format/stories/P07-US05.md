## User story

As a presentation consumer, I want slide text, shapes, media, tables, and
transforms preserved as native evidence, so that slide order and geometry do
not depend on OCR.

## Business value

Enables grounded slide-level retrieval, retains editable spatial structure, and
creates the native substrate for later Office-chart and bounded-fallback
stories.

## Problem statement

The parser has no PPTX adapter. Flattening slides to images loses shape
identity, z-order, group transforms, tables, and relationship provenance, while
mixing chart or fallback work into the adapter would exceed a bounded story.

## In scope

- Slide order, policy-visible text runs/placeholders, shapes/groups, media,
  native tables, z-order, and slide/group coordinate transforms.
- Source part/XML locator, relationships, element IDs, visibility, and basic
  style/type metadata needed for semantics.
- Chart/drawing placeholders and concerns for P07-US07/P07-US08.

## Out of scope

- Native chart data extraction, which belongs to P07-US07.
- Rendering or visual fallback, which belongs to P07-US08.
- Speaker-note semantics, SmartArt reconstruction, animation, transitions,
  audio/video transcription, macros, or legacy `.ppt`.

## Technical approach

Traverse approved presentation/slide/master/relationship parts from P07-US03,
compose group and slide transforms into declared coordinates, emit visible
native elements in deterministic z/order, and defer charts and unsupported
drawings as linked placeholders.

## Acceptance criteria

1. Approved fixtures preserve slide order, policy-visible text, shape/media
   type, table structure, z-order, and relationships exactly once.
2. Shape and nested-group geometry round trips to source slide coordinates
   within 0.5 point on fixture transforms.
3. Every emitted element records `native_xml`, source part/XML locator, slide
   ID, and applicable relationship/transform provenance.
4. Hidden slides and hidden elements follow documented policy with zero
   accidental visible-content leakage.
5. Chart and unsupported drawing parts are linked placeholders with concerns;
   no chart values or visual fallback are produced in this story.
6. Unsafe/over-budget packages fail through P07-US03, and flag-off restores
   prior unsupported-format behavior.

## API and schema compatibility

Adds a flagged PPTX MIME/extension path and additive slide/native provenance.
Existing format responses remain unchanged; chart/fallback fields are not added
by this story.

## Risks

- Master/theme/placeholder and nested-transform inheritance is complex.
- Z-order and grouping semantics can vary across producers.
- Unsupported SmartArt can tempt unsafe semantic reconstruction.
- OOXML reader dependencies require license/security review.

## Rollback

Disable the PPTX adapter and stop advertising PPTX support. Return the existing
unsupported-format response without full-slide rendering.
