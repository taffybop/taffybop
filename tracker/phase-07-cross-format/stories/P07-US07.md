## User story

As a chart-data consumer, I want PPTX and XLSX chart structure and values read
from native Office evidence, so that exact embedded data takes precedence over
visual measurement.

## Business value

Improves chart accuracy and provenance at low compute cost, avoids false visual
precision, and reuses the Phase 05 validation/serialization contract.

## Problem statement

PPTX and XLSX adapters currently defer chart parts. Office charts can reference
worksheet cells, embedded workbooks, or cached series that disagree or are
stale. Selecting one without provenance and validation can emit confident but
incorrect data.

## In scope

- PPTX/XLSX chart parts, titles, axes, legends, categories, series, units,
  values, and relationships.
- Worksheet/workbook references, embedded data, and cached chart values as
  separate evidence candidates.
- Native-data selection, conflict/staleness concerns, and Phase 05 validation.
- `embedded_data`/`native_xml` provenance and canonical chart projection.

## Out of scope

- Visual chart measurement or rendering, which belongs to P07-US08.
- Recalculating formulas, fetching external workbooks, or guessing missing
  values.
- Unsupported chart-type reconstruction or semantic completion.
- DOCX chart extraction in this story.

## Technical approach

Resolve chart relationships through the secure package graph, map series and
categories to native cell/embedded/cache evidence, prefer valid direct native
data, retain conflicts as alternatives, and pass candidate structure through
P05-US05 before canonical projection.

## Acceptance criteria

1. Supported PPTX/XLSX fixtures recover chart title, axes, legends, categories,
   series, units, and values with source part and relationship provenance.
2. When valid direct cell/embedded data exists, 100% emitted points use
   `embedded_data` or equivalent native provenance and no visual value is
   selected.
3. Every emitted point links to its chart part plus source cell, embedded
   workbook, or explicit cache evidence and validation result.
4. Missing, stale, conflicting, external, or malformed references remain
   alternatives/concerns; formulas and external workbooks are not executed or
   fetched.
5. Structurally or numerically invalid chart data is withheld through P05-US05
   rather than corrected by guess.
6. Unsupported chart types retain native labels/relationships and a concern for
   P07-US08, with no fabricated values.
7. Flag-off chart placeholders from P07-US05/P07-US06 remain unchanged.

## API and schema compatibility

Adds flagged chart structure through the existing additive Phase 05 contract.
No existing fields are removed; flag-off placeholders and existing formats
remain unchanged.

## Risks

- Cached data may conflict with worksheets or embedded workbooks.
- Producer-specific chart XML and formula references vary.
- Downstream consumers may ignore evidence-method distinctions.
- Unsupported chart types can expose incomplete labels or relationships.

## Rollback

Disable Office chart extraction and retain linked chart placeholders for
P07-US08 or explicit unsupported output.
